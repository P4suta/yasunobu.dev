# Yasunobu.dev

Personal homepage at sakashita.yasunobu.dev.

## Installation

```sh
git clone https://github.com/P4suta/yasunobu.dev.git
cd yasunobu.dev
mise trust
mise install
mise x -- npm ci
```

## Usage

```sh
mise x -- npm run dev
```
